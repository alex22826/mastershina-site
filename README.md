# MASTERSHINA — новый сайт (главная страница)

Редизайн сайта [mastershina.uz](https://mastershina.uz/): грузовые шины ROADONE и CETROC, шины для спецтехники HENGTAR, диски SULTAN, запчасти HOWO / SHACMAN. Ташкент.

**Смотреть:** https://alex22826.github.io/mastershina-site/

Цвета — красный, чёрный, белый. Стилистика, кнопки и анимации взяты из демо [CANDY](https://alex22826.github.io/mastershina-demo-candy/).

## Что на главной

1. **Прелоадер-колесо** — колесо закатывается, крутится, пока грузится сайт, и укатывается; сайт плавно проявляется.
2. **Баннер** — 4 слайда (ROADONE, HENGTAR, диски SULTAN, опт и рассрочка), на каждом круглое колесо въезжает с вращением; свайп на телефоне, полоска-таймер в точках.
3. **Подбор шин и дисков** рядом с баннером (как в демо CANDY) — вкладки «Шины / Диски», режимы «По параметрам» (тип, диаметр, ось, производитель) и «По технике» (6 видов техники), быстрые размеры, кнопка «Найти шины (N)» фильтрует витрину.
4. **Каталог категорий** — 4 карточки, количество моделей считается из данных.
5. **Витрина продукции** — карусель с фильтрами, избранное, кнопка «В корзину» превращается в счётчик.
6. **О компании** — бенто-блок с фото и счётчиками + 6 преимуществ.
7. **Популярные бренды** — по клику фильтрует витрину (если бренда нет в каталоге — открывает заявку).
8. **Частые вопросы** — плавное раскрытие, открыт один вопрос.
9. **Карта и контакты** — 3 шоурума со статусом «открыто/закрыто» по времени Ташкента, кнопки «Маршрут», Яндекс-карта.
10. **Футер** и на телефоне — **нижняя панель** (Каталог · Подбор · Корзина · Звонок).

Плюс корзина, оформление заказа с выбором оплаты (Payme, Click, Uzum, карты, при получении), обратный звонок, живой поиск.

## Скорость на слабом интернете

- Прелоадер встроен в HTML — показывается сразу, ещё до загрузки CSS. Основной CSS грузится без блокировки отрисовки.
- Прелоадер ждёт только **первый экран** (стили, шрифт, картинки первого слайда), а не всю страницу. Максимум 7 секунд — дальше сайт показывается, остальное догружается.
- Шрифт Rubik лежит локально (2 файла, 50 КБ), без Google Fonts.
- Картинки — WebP 15–30 КБ; всё, что ниже первого экрана, грузится лениво. Слайды 2–4 и картинки меню — только когда нужны.
- Яндекс-карта (≈1 МБ) подгружается, только когда до неё доскроллили; на 2G и в режиме экономии трафика — только по кнопке.
- Бесконечные анимации на паузе, когда блок вне экрана; нет `backdrop-filter`, `filter: blur/drop-shadow` на анимированных элементах.
- Первый экран: ~290 КБ без сжатия (≈170 КБ с gzip на GitHub Pages).

## Адаптив

Ноутбук ≤1240 · планшет альбомный ≤1100 (подбор под баннером, поля и техника в один ряд) · планшет ≤900 (бургер, поиск по кнопке) · телефон ≤768 (нижняя панель) · ≤640 · маленькие телефоны ≤380. Hover-эффекты только для мыши — на телефоне карточки не «залипают».

## Структура

```
index.html             — разметка + встроенный прелоадер
assets/css/style.css   — стили
assets/js/data.js      — каталог, шоурумы, оплата (демо-цены)
assets/js/core.js      — корзина, оформление, оплата, анимации появления
assets/js/main.js      — баннер, подбор шин и дисков, витрина, бренды, FAQ, карта
assets/fonts/          — Rubik (кириллица + латиница)
assets/img/            — фото товаров и компании, рендеры колёс (decor/)
tools/cutout.py        — вырезка студийного фона в WebP с прозрачностью
```

## Запуск

```bash
python -m http.server 8790
```

## Что уточнить у клиента перед запуском

- Цены, остатки, рейтинги в `data.js` — демонстрационные (в будущем — из 1С / API).
- Срок рассрочки на стикере баннера («до 12 мес»).
- Какие товары подходят какой технике в подборе — объект `VEHICLES` в `main.js`.
- Координаты шоурумов на Янги Сергели (сейчас маршрут строится по адресу).

## Изображения

- `assets/img/decor/` — студийные рендеры колёс и диска (вид почти сбоку, круглые) для баннера, категорий и меню. Сгенерированы ИИ (Higgsfield, модель Z Image), фон вырезан скриптом, без логотипов и надписей. Это декор «шины вообще», а не конкретные модели.
- `assets/img/products/` — реальные фото товаров с mastershina.uz (фон удалён). В карточках витрины нужны именно они: покупатель смотрит на рисунок протектора. Лучшая замена — фото со склада клиента.

## Эквайринг

Точка интеграции — `startPayment(order)` в `assets/js/core.js`. Сейчас имитация; в рабочей версии — запрос к backend, который создаёт счёт в Payme / Click / Uzum и возвращает ссылку на страницу оплаты.
